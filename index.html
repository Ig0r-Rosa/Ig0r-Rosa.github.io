Sobre o Archivus

// drive Markdown · Kanban · autores · público /@user
~/repos/Archivus/README.pt.md

O Archivus é uma aplicação para transformar um volume de notas em biblioteca estruturada: cada usuário tem seu drive (pastas e documentos em Markdown), um Kanban pessoal e uma inbox para conversar com outros autores — com suporte a transferência de tarefas entre quadros. Conteúdo marcado como público fica disponível em URLs /@username/… sem que visitantes precisem de conta.

A stack é deliberadamente clássica: PHP 8.3, Laravel 13, renderização server-side com Blade, estilos com Tailwind 3 e interações leves com Alpine 3; assets via Vite 8. Em desenvolvimento o padrão é SQLite, com caminho para MySQL/PostgreSQL em produção. Licença MIT.

Funcionalidades em foco

  • Drive e Markdown — hierarquia de pastas e arquivos, publicação por documento ou por pasta inteira; editor com CommonMark/GFM, paste de imagens, blocos HTML, realce de sintaxe e pré-visualização ao vivo.
  • LaTeX e media — equações inline e em bloco com KaTeX; embeds automáticos para YouTube, Vimeo, Google Drive e arquivos .mp4 a partir de imagens Markdown.
  • Kanban — colunas predefinidas e extras, prioridades, arrastar e soltar, texto Markdown nos cartões.
  • Mensagens entre autores — conversas 1‑para‑1 com Markdown e imagens, polling em “tempo quase real” e fluxo de oferta/aceitação/recusa/expiração para mover tarefas entre autores.
  • Descoberta pública — perfil e documentos em /@user, pesquisa em /pesquisar e /trending para encontrar autores.
  • i18n e acessibilidade de UI — locale por sessão (pt_BR / en) e tema claro/escuro persistente em localStorage.
  • Ajuda em Markdown na própria app — conteúdos em resources/markdown-help/ servidos publicamente, por exemplo em /@demo/ajuda e /@demo/help, com slugs espelhados entre idiomas via config/archivus.php.

Como experimentar (resumo)

Clonar o repositório, composer install e npm install, copiar .env.example, gerar chave, configurar APP_URL (ex. porta 5077), APP_LOCALE e SQLite, rodar migrações, npm run build (ou npm run dev para HMR) e php artisan serve --port=5077. Há variante Docker (docker compose up -d) com Nginx na porta 5077. Documentação de rotas, modelos e fluxos: arquivo ARCHIVUS.md no repositório.
